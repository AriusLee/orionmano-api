# Company Teaser Template

**Audience:** Potential investors (initial interest generation)
**Format:** PDF, 2-4 pages
**Purpose:** Concise, compelling overview to generate investor interest without full disclosure

## Document Structure

### Page 1: Company Snapshot

**Header:** ORIONMANO logo + "Strictly Private and Confidential"

**Company Overview Box:**
- Company name (or code name for blind teasers)
- Industry / sector
- Headquarters location
- Year of incorporation
- Transaction type: "[IPO / Fundraising / Strategic Partnership]"

**Investment Highlights (5-6 bullet points):**
- Market leadership / positioning statement
- Revenue scale and growth trajectory
- Profitability profile
- Competitive advantages / moats
- Market opportunity size
- Strategic milestones achieved

### Page 2: Business at a Glance

**Business Description (2-3 paragraphs):**
- What the company does
- Key products/services
- Geographic presence
- Customer base overview

**Key Financial Metrics Table:**
| Metric | FY [Y-2] | FY [Y-1] | FY [Y] | CAGR |
|--------|----------|----------|--------|------|
| Revenue | | | | |
| Gross Profit | | | | |
| EBITDA | | | | |
| Net Income | | | | |
| Gross Margin | | | | |
| EBITDA Margin | | | | |

**Revenue Breakdown:**
- By segment (pie chart or bar chart)
- By geography (if multi-market)

### Page 3: Market Opportunity

**Industry Overview:**
- Market size and growth rate (1-2 sentences)
- Key growth drivers (3-4 bullets)
- Company's market share / positioning

**Competitive Advantages:**
- 4-5 key differentiators with brief descriptions

### Page 4: Transaction Overview

**Offering Summary:**
| Item | Detail |
|------|--------|
| Offering Type | [Primary / Secondary / Combined] |
| Target Exchange | [Nasdaq Capital Market / Nasdaq Global Market / Nasdaq Global Select Market / NYSE / NYSE American] |
| Estimated Size | [Range] |
| Use of Proceeds | [Brief] |
| Expected Timeline | [Quarter/Year] |

**Contact Information:**
- Orionmano advisory team contact
- NDA requirement note

**Disclaimer:**
- This teaser is for information purposes only and does not constitute an offer
- Subject to execution of NDA before detailed information is provided

## Design Guidelines
- Premium, polished design — first impression document
- Maximum 4 pages — brevity is key
- Visual-heavy: charts, icons, highlight boxes
- No sensitive financial detail beyond what's publicly available
- Use metrics that highlight growth and profitability
- Compelling but factual — avoid puffery
