# Gap Analysis Report Template — Transaction Grade

**Audience:** Client management, advisory team, prospective engagement decision-makers
**Format:** PDF
**Branding:** Orionmano Assurance Services
**Classification:** STRICTLY CONFIDENTIAL
**Purpose:** Assess a private company's readiness for Nasdaq listing and provide a transaction-grade roadmap to close identified gaps. This is NOT a narrative summary — it is a decision-grade advisory memo.

---

## Section 1: Assumptions & Listing Path

The FOUNDATION of the entire report. Must be established before any gap analysis can be accurate.

| Item | What to Cover |
|------|--------------|
| **Nasdaq Tier** | Capital Market / Global Market / Global Select — recommend based on company financials with rationale |
| **Registration Path** | F-1 (FPI) vs S-1 — determine FPI qualification |
| **Listing Vehicle** | Direct listing of existing entity, or topco restructure / redomicile / holdco insertion required? |
| **IPO Mechanism** | Firm commitment IPO / best efforts / direct listing / de-SPAC |
| **Key Dependencies** | What must be true for this path to work |

Without this section, all downstream analysis may be based on wrong assumptions.

---

## Section 2: FPI Status & Reporting Regime

Determines the entire compliance architecture. Getting this wrong cascades errors throughout the report.

**Key FPI implications:**
- FPI can use IFRS as issued by IASB (no US GAAP conversion required)
- FPI files 20-F (annual) and 6-K (interim), NOT 10-K/10-Q/8-K
- Reg FD does NOT apply to FPIs
- Many Nasdaq governance rules have home country practice exemptions (EXCEPT audit committee independence)
- FPIs are not required to file quarterly earnings in 10-Q format

## Section 9: Audit & Accounting Readiness

Must go DEEPER than "get a PCAOB audit":

- IFRS vs US GAAP path (based on FPI determination)
- Revenue recognition complexity (specific to business model)
- Deferred revenue, prepaid, wallet balances
- Token/digital asset accounting (if applicable)
- Principal vs agent determination
- Related-party cleanup
- Tax / transfer pricing exposure
- Consolidation issues
- SOX 302/404 readiness

## Key Principles

- **NO inline citations** — state basis naturally ("Based on FY20XX audited financials")
- **Data consistency** — ONE set of canonical numbers used throughout
- **Flag missing data** — "Information Required" with description of what's needed
- **Forward-looking timelines** — never reference past dates in action plans
- **FPI-aware** — adjust all analysis based on FPI determination
- **Transaction-grade** — every section must pass the "would a banker take this seriously?" test
